## 🔧 Projects

### 🚗 Neuro-Controlled Car (Eye-Blink BCI)
A brain-computer interface car controlled entirely by **eye blinks** — no joystick, no hands.
- EOG signal pipeline: BioAmp EXG Pill → analog filtering → spike detection → command classification
- Wireless transmission via nRF24L01 (250KBPS SPI) across dual-Arduino architecture
- Single blink = forward, double blink = backward — tested on physical hardware
- `Arduino C++` `nRF24L01` `BioAmp EXG Pill` `L298N` `EOG Signal Processing`

### 🌾 FarmLink AI — Agri-Fintech Investment Platform
A platform connecting retail investors with verified Indian farmers.
- Multilingual AI pipeline: Telugu → English farmer field updates for investors
- ₹500 minimum investment — targeting students + ESG institutional investors
- Farmer verification, legal agreements, NGO onboarding network
- `Python` `LLM APIs` `Agri-Fintech` `Product Design`
